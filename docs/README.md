# Docs — The Code Doctors

This folder is the persistent knowledge base for the project.
Every meaningful decision, plan, and progress update lives here.

## Index

- [`../CLAUDE.md`](../CLAUDE.md) — master context loaded automatically by Claude Code
- [`PORTAL-SPEC.md`](PORTAL-SPEC.md) — product spec for the patient + practice portals (IA, journeys, permissions, layout, mobile, notifications, data model)
- [`ROADMAP.md`](ROADMAP.md) — 7 phases of the build with status checkboxes
- [`ARCHITECTURE.md`](ARCHITECTURE.md) — stack, infra, three-surface architecture
- [`BRAND.md`](BRAND.md) — voice, vocabulary, palette, typography
- [`SECURITY-POSTURE.md`](SECURITY-POSTURE.md) — non-negotiable security checklist
- [`BUILD-LOG.md`](BUILD-LOG.md) — append-only log of what was built each session
- [`decisions/`](decisions/) — architecture decision records (ADRs)

## Conventions

- **ADRs** are dated, numbered, and append-only. Filename: `NNNN-short-title.md`.
- **Build log** entries are added at the top of `BUILD-LOG.md` (newest first).
- **Roadmap checkboxes** are ticked as work ships, not as it starts.
- **Brand voice and vocabulary** are reviewed before any new copy ships — see `BRAND.md`.
- **Security posture** is reviewed before any deploy — see `SECURITY-POSTURE.md`.
